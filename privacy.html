1. 이 앱은 무엇인가요

autoreply는 [회사명]이(가) 운영하는 유튜브 채널에서, 직원이 예약한 시간에 자기 채널 영상의 댓글을 작성하고 수정하는 내부 업무용 프로그램입니다. 일반 이용자에게 제공하는 서비스가 아니며, 회사가 소유한 채널에서만 사용합니다.

2. 이용하는 정보

Google 계정으로 로그인해 권한을 허용하면, YouTube API 서비스를 통해 아래 정보에 접근합니다.

정보용도
채널 ID, 채널 이름로그인한 채널이 맞는지 확인
영상 목록, 제목, 공개 상태, 예약 공개 시간, 길이새 영상 공개 시각 확인, 롱폼·쇼츠 구분
채널 운영자가 직접 작성한 댓글예약된 댓글 작성, 기존 고정 댓글 문구 수정
채널 로그인 정보(OAuth 토큰)예약 시간에 자동으로 작업하기 위해 보관
직원의 Google 계정 이메일, 이름등록된 직원인지 확인

시청자 개인정보(다른 사람의 댓글 내용, 시청 기록 등)를 수집하거나 저장하지 않습니다.

3. 이용 목적

위 정보는 회사 채널의 댓글 작성·수정 자동화에만 사용합니다. 광고, 마케팅, 분석 판매에 사용하지 않습니다.

4. 제3자 제공

수집한 정보를 제3자에게 판매하거나 제공하지 않습니다. 단, 법령에 따라 요구되는 경우는 예외로 합니다.

5. 보관과 파기

  • 채널 로그인 정보: 앱 사용을 중단하거나 권한을 철회할 때까지 보관하며, 중단 시 즉시 삭제합니다.
  • 예약·실행 기록: 6개월 보관 후 삭제합니다.
  • 보관 위치: 회사가 관리하는 컴퓨터(서버). 접근은 등록된 담당 직원으로 제한합니다.

6. 권한 철회

언제든지 Google 계정 설정에서 이 앱의 접근 권한을 철회할 수 있습니다.

  • https://myaccount.google.com/permissions → autoreply → 액세스 권한 삭제
